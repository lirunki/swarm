Sessions and controls

New agent starts pi. Adopt session offers saved pi conversations or Grok history converted into pi; adopted/imported sessions stay offline until you Wake them. Closing a terminal tab does not stop its agent. Wake resumes; Stop terminates and disables automatic restore. Edit → Forget removes an inactive agent while keeping its saved session history.

Terminal scrolling and copying

On mobile, swipe down for older output and up for newer output. At the bottom, tap to type. Copy text puts the visible screen in a read-only layer directly over the terminal: use native selection handles and Copy. It closes after copying, or tap Done copying. Only the visible screen is captured—scroll first for other text.

While the mobile software keyboard is open, the terminal key bar adds Ctrl, Alt, arrows, Esc and Supr (forward Delete). Ctrl and Alt apply to the next typed key or accessory key, then reset; tap both for a combined shortcut. The bar keeps the keyboard focused and hides when it closes, when you leave the terminal, or while copying.

On desktop, hold Shift while dragging to select past tmux mouse handling, then use your browser or system Copy command. Desktop terminals have no extra copy layer.

Relay and safety

The Swarm selector changes workspace. The gear always configures the local relay connection. A relay joins fully trusted controllers: peers can control agents and read data. Keep the dashboard on localhost, HTTPS, or a trusted network. Restart backend reloads the controller, not its tmux-backed agents.

BRING YOUR HISTORY

Adopt a pi session

Register an inactive session without copying it or starting pi. Its original folder and conversation stay intact. Wake it when you're ready.

If a pi process is running in the same folder, adoption is conservatively blocked. Quit that pi process, then refresh.
CONTINUE IN PI

Import Grok session

Convert a saved Grok Build conversation into a new pi session, then adopt it offline. Original Grok files stay unchanged. Stop Grok before waking the imported agent.

Windows drive paths are mapped to /mnt on WSL. Override this folder if the project moved. Tool exchanges become historical text; original records remain archived in pi. Grok credentials, memory and tools are not installed.

Wake agent

Continue the exact saved session. Leave instructions empty to wake it without submitting any prompt. For a live agent, nonempty instructions are queued in its terminal.

Edit agent

Changing a status only updates the record; it does not start, pause, or stop the process. Use Wake or Stop for process control.
