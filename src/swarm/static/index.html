      Notifications and broadcast

      The bell beside the Swarm logo combines unread notifications from every connected Swarm and groups each agent's messages together. Agents must notify you whenever they need your action or complete your request. Open agent clears every notification in that agent's group, selects its source Swarm, and opens an existing live terminal tab or reveals and highlights its card. Clear all flushes every available notification across connected Swarms.

      The dialog also contains Master control, Settings and Restart active Swarm. Type a message and use Select & broadcast to choose managed agents by checkbox, Swarm, process state or search. Only shown checked agents receive it. Broadcast queues durable messages without waking agents; inspect request IDs for uncertain results instead of retrying blindly.

      Sessions and controls

      New agent starts pi. Its bottom-left Adopt session menu offers saved pi conversations or Grok history converted into pi; adopted/imported sessions stay offline until you Wake them. Closing a terminal tab does not stop its agent. Wake resumes; Stop terminates and disables automatic restore. Edit → Forget removes an inactive agent while keeping its saved session history.

      Terminal scrolling and copying

      On mobile, swipe down for older output and up for newer output. At the bottom, tap to type. Copy text puts the visible screen in a read-only layer directly over the terminal: use native selection handles and Copy. It closes after copying, or tap Done copying. Only the visible screen is captured—scroll first for other text.

      While the mobile software keyboard is open, the terminal key bar adds Esc, Tab, Ctrl, Alt, arrows, Home, End and Sup (forward Delete). Ctrl and Alt apply to the next typed key or accessory key, then reset; tap both for a combined shortcut. The bar keeps the keyboard focused and hides when it closes, when you leave the terminal, or while copying.

      On desktop, hold Shift while dragging to select past tmux mouse handling, then use your browser or system Copy command. Desktop terminals have no extra copy layer. The tmux button beside Files can split the current window, close a selected split pane, open/switch windows, move focus and zoom panes. New splits and windows start Bash in the agent's working folder. The main agent pane cannot be closed from this menu.

      Files

      Files on a card or beside Reconnect opens its library. Upload picks a file on your browser's computer and saves a copy in the selected agent machine's temporary folder. Paste or Ctrl+V / ⌘V inside Files can also upload a copied image/file. The Paste button may require HTTPS/localhost and clipboard permission; plain text/URLs are not uploaded. Upload does not send a prompt. Download retrieves it; Insert pastes its quoted local path into a live agent's input without pressing Enter. Continue typing and submit when ready.

      Agents can also register existing server files with swarm file add. Only metadata loads first; Open/Download reads bytes on demand. Remove reference keeps existing originals. Remove upload deletes only the uploaded temporary copy, never your browser-side original. Keep important inputs in durable storage: OS temp cleanup can make references unavailable.

      Relay and safety

      The Swarm selector changes workspace. Settings in Notifications always configures the local relay connection. A relay joins fully trusted controllers: peers can control agents and read data. Keep the dashboard on localhost, HTTPS, or a trusted network. Restart backend reloads the controller, not its tmux-backed agents.

      Convert a saved Grok Build conversation into a new pi session, then adopt it offline. Original Grok files stay unchanged. Stop Grok before waking the imported agent.
