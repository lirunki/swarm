      Dashboard

      Each tile is an independent agent. Expand it for goal, activities, checkpoint and controls. Open the state dropdown to search by text and show several states together; All checks or clears every state. Counts update live. Press / to open the menu and focus search. Search covers full card metadata: names, goals, activity titles, checkpoint/details, products and registered file labels/names—even while the card is compact. It does not read file contents or terminal history. Dimmed ancestors remain to explain parent → child relationships. When an agent has several visible sub-agents, use the small − / + control at their branch join to group or show the whole child branch. That grouping is part of browser-local UI view state and is remembered independently for each Swarm backend.

      Agent groups

      Select cards using their checkbox or Ctrl/⌘-click. Parents, children and siblings move as one family, including hidden descendants. Right-click → Grouping (or the selection toolbar) offers Default group, New group and saved groups. Shift+F10 opens the menu from a focused card.

      Blue folder tiles show each group's agent count. Only the active folder appears as a tab immediately after Dashboard, followed by its terminal tabs. Use Dashboard and its folder tiles to switch groups; Dashboard shows ungrouped agents. Hidden terminal tabs stay alive. Dashboard/folder tabs are bold and brighter than tmux tabs. Click the group name ▾ for Rename/Delete; return through the Dashboard tab. These actions change grouping only, never agent processes. The grouping-storage switch in Settings chooses owner-server or browser-local folders, membership and branch grouping. First enable asks whether to prime from this browser. Viewing A through B saves server grouping on A. Active views and terminal tabs stay browser-local.

      Notifications and broadcast

      The bell beside the Swarm logo combines unread notifications from every connected Swarm and groups each agent's messages together. Agents must notify you whenever they need your action or complete your request. Open agent clears every notification in that agent's group, selects its source Swarm, and opens an existing live terminal tab or reveals and highlights its card. Discard clears only that agent's notification group without navigating away. Clear all flushes every available notification across connected Swarms. Enable OS alerts asks the browser for permission and then displays only newly arriving bell items through the operating system, including Android notifications. Browser notifications require localhost or HTTPS. This preference is local to the browser; the dashboard must remain open to receive events because Swarm does not use a remote push service.

      The dialog also contains Master control, Settings and Restart active Swarm. Settings holds active-agent limits, grouping storage, mouse-wheel speed and a collapsed local-relay section. Type a message and use Select & broadcast to choose managed agents by checkbox, Swarm, process state or search. Only shown checked agents receive it. Broadcast queues durable messages without waking agents; inspect request IDs for uncertain results instead of retrying blindly.

      Sessions and controls

      New agent starts pi. Its bottom-left Adopt session menu offers saved pi conversations or Grok history converted into pi; adopted/imported sessions stay offline until you Wake them. Closing a terminal tab does not stop its agent. UI view state remembers open terminal tabs and the selected tab only in this browser, independently for each Swarm backend. Wake resumes; Stop terminates and disables automatic restore. Edit → Forget removes an inactive agent while keeping its saved session history.

      Terminal scrolling and copying

      On mobile, swipe down for older output and up for newer output. At the bottom, tap to type. Copy text sits immediately left of the product button (⧉ on narrow screens, ✓ while selecting). It puts the visible screen in a read-only layer directly over the terminal: use native selection handles and Copy. It closes after copying, or tap Done copying. Only the visible screen is captured—scroll first for other text.

      While the mobile software keyboard is open, the terminal key bar adds Esc, Tab, Ctrl, Alt, arrows, Home, End and Sup (forward Delete). Ctrl and Alt apply to the next typed key or accessory key, then reset; tap both for a combined shortcut. The bar keeps the keyboard focused and hides when it closes, when you leave the terminal, or while copying.

      On desktop, hold Shift while dragging to select past tmux mouse handling, then use your browser or system Copy command. Desktop terminals have no extra copy layer. After the connection state, the terminal toolbar shows Product, Files, mail count, tmux and Reconnect in that order. Product uses a short blue label and opens or downloads that agent's latest published result. The mail button opens that agent's durable messages and highlights a nonzero outstanding count. On mobile widths, Copy text, Product, Files and Reconnect collapse to icons while mail keeps its icon and count and tmux keeps its menu label. The tmux button beside Files can split the current window, close a selected split pane, open/switch windows, move focus and zoom panes. New splits and windows start Bash in the agent's working folder. The main agent pane cannot be closed from this menu.

      Files

      Files on a card or beside Reconnect opens its library. Upload picks a file on your browser's computer and saves a copy in the selected agent machine's temporary folder. Paste or Ctrl+V / ⌘V inside Files can also upload a copied image/file. The Paste button may require HTTPS/localhost and clipboard permission; plain text/URLs are not uploaded. Upload does not send a prompt. Download retrieves it; Insert pastes its quoted local path into a live agent's input without pressing Enter. Continue typing and submit when ready.

      Agents can also register existing server files with swarm file add. Only metadata loads first; Open/Download reads bytes on demand. Remove reference keeps existing originals. Remove upload deletes only the uploaded temporary copy, never your browser-side original. Keep important inputs in durable storage: OS temp cleanup can make references unavailable.

      Relay and safety

      The Swarm selector changes workspace. Settings separates selected-server capacity/grouping, this browser's wheel speed, and the local relay connection. A relay joins fully trusted controllers: peers can control agents and read data. Keep the dashboard on localhost, HTTPS, or a trusted network. Restart backend reloads the controller, not its tmux-backed agents.
